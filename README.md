# Kube Credential - Frontend React Application

## Description
React (TypeScript) frontend with two pages: one for issuing credentials, another for verifying them. Interacts with backend microservices via JSON APIs.

Built for simplicity and clear UI feedback. Can be deployed as a static site or web service.

## Setup
1. Clone repo
2. Run `npm install`
3. Start dev server: `npm run dev`
4. Build production bundle: `npm run build`

Supports Docker containerization and Kubernetes ingress manifests.

## Features
- Issuance and Verification pages
- API integration with backend services
- JSON input/output with real-time response display
